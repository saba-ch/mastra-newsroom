# Take-home project: Mastra mini app (timebox: ~4 hours)

Build a small Mastra project that demonstrates agents + tools + workflows, and can be run and inspected in Mastra Studio. Studio should clearly show the agent runs, workflow steps, and outputs.

## What to build

A "Daily News Reporter" that accepts a topic (e.g. "AI regulation", "climate tech") and returns a news report.

Include at least:

- 1 agent that uses 1 or more tools
- 1 workflow with multiple steps (branching optional)
- 1 custom scorer
- 1 external integration
- A Mastra dataset with at least 5 items that can be used in experiments
- A runnable Studio setup so we can reproduce and demo it locally

The focus is on Mastra and its primitives, not any UI or app built around the agents/workflows.
